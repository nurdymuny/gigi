# Yang Mills adversarial review evidence

Companion to Bee Rosa Davis's
[research note](../../docs/research/yang-mills-geometric-identities-adversarial-review-2026-11-23.md).
Reviewed source: `b418ef79789769c9ea0ce2ae51906de0bcbc3141`.

**This directory contains intentionally incorrect evidence accepted by the
submitted gates. It is not a collection of passing physical experiments.**

| File | Meaning |
| --- | --- |
| `review.json` | Authoritative audit summary, scope exclusions, source and artifact hashes, numerical warnings |
| `plaquette-baseline.json` | Fresh execution of the unmodified single-plaquette calculation |
| `replay.log` | Execution trace; includes deliberately corrupted fixture replays, not only baseline calculations |
| `wrong-shift-submitted-receipt.json` | Counterexample: the applied energy shift is 1,000 times the declared one, but the submitted gate accepts it |
| `collapsed-gap-reducer-receipt.json` | Counterexample: committed fixtures with five-plaquette gaps replaced by `1e-12`; accepted by the submitted aggregation logic; not simulated physics |
| `stale-submitted-receipt.json` | Counterexample: a preceding PASS left intact after the submitted runner exits unsuccessfully |
| `prior-rtc-replay-63588263.json` | Historical cell replay from the preceding review; not rerun in this audit |

Reproduce with `scripts/ym_geometry_adversarial_review.py`, writing to a separate
output directory as specified in the note. No excitation-study verdict is
provided. The historical cell receipt is not regenerated by that command.
Recorded text hashes normalize CRLF to LF to match Git storage across platforms.
