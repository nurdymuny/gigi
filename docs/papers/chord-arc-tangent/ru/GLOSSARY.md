# English → Russian glossary for the Russian edition

Shared by every translator of *Three Ways Across a Turn* and of the chapter
*Thank You, Mr. Perelman*. Use these terms every time; do not vary them for style.
Register: a careful Russian mathematical paper (as in Успехи математических наук), plain
and exact, with the author's directness kept. The «Простыми словами» boxes are deliberately
plain, conversational Russian.

## Typography and conventions

- Dashes between names: «Кранка — Николсон», «Снеллиуса — Гюйгенса», «Янга — Миллса»
  (spaced em dash in running text; in LaTeX write `"---` or ` --- `).
- Quotation marks: «ёлочки», inner „лапки“.
- Decimal separator inside running text stays a point when it is inside math mode (keep the
  math exactly as written); numbers in prose may stay as in the source (do not reformat).
- Keep every LaTeX command, label, ref, cite, equation and math expression exactly as in the
  source. Translate only human-language text, including captions, \paragraph titles, TikZ
  node labels that are words, table headers, and \texttt descriptions that are prose.
  Never translate file paths, code, identifiers (verify.py, SYMPLECTIC_FLOW), or citation keys.
- Names: Archimedes — Архимед; Snellius — Снеллиус; Huygens — Гюйгенс; Cayley — Кэли;
  Wilson — Вильсон; Manton — Мантон; Crank — Кранк; Nicolson — Николсон; Bertrand — Бертран;
  Jaynes — Джейнс; Feynman — Фейнман; Singer — Зингер; Milnor — Милнор; Perelman — Перельман;
  Thales — Фалес; Pythagoras — Пифагор; Poincaré — Пуанкаре; Hamilton — Гамильтон;
  Bee Rosa Davis — Би Роза Дэвис (on the title page keep the Latin original as well).
- Numbers: keep every number exactly as in the source, including decimal points (math and
  prose alike), so text and formulas never disagree. The edition notes this convention.
