# CLAUDE.md

Agent-facing instructions for this repo live in **[`AGENTS.md`](AGENTS.md)**.

Read it before working on GIGI or filing a defect against it. It exists because
coding agents keep hitting the same handful of traps — a refusal mistaken for a
bug, a stale binary, a `{"status":"ok"}` that executed nothing — and reporting
the engine as broken. Every trap documented there actually happened.

Human-facing docs are indexed in [`README.md`](README.md); the shape verbs
(TEXTURE / PRECEDENCE / CADENCE) have their own guide at
[`docs/SHAPE_VERBS.md`](docs/SHAPE_VERBS.md).
