## What the draft changes so far

- **New §7.4, "The Edge at C = 1".** The capacity law is exact: the posterior passes 1/2 if and only if C > 1. So
  C = 1 is where the more probable hypothesis changes hands. The section points to the same shape in the Floor
  Theorem (doi:10.5281/zenodo.24412603) and in *By Enough, But Not Too Much* (draft, `docs/papers/by-enough`): there,
  the floor changes hands at a single crossing. The bridge is tagged as one of form; no theorem connects the two.
- **Proposition 5, last sentence.** The published text said the tools behave as taught "when all three are near 1".
  At τ/K = 1 the posterior is exactly 1/2, which is the edge, not the benign case. The sentence now says so.
